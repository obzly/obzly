The first release of Obzly from this repository: logs, traces and metrics on Postgres and object
storage, with Sites, a control plane and synthetic monitoring probes.

It contains everything up to v0.58.1, plus:

- the UI's static file handler cleans request paths before it looks for a file, so a request
  can't reach outside the UI's directory;
- alert mail parses the From and recipient addresses before it connects, and refuses an address
  that would add a header.

No migration. Upgrading from v0.58.x is a normal upgrade: Sites first, then the control plane,
then the probes (see the upgrade runbook).
