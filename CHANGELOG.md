# Changelog

Each release's notes are published with the release on
[GitHub Releases](https://github.com/obzly/obzly/releases): a summary, its images
(`ghcr.io/obzly/obzly:<version>` and `ghcr.io/obzly/obzly-probe:<version>` for `linux/amd64` and
`linux/arm64`) and the pull requests merged since the previous release (see "Commit messages and
versioning" in [CONTRIBUTING.md](CONTRIBUTING.md)).

Releases that need action from operators - a new permission, a setting, a one-way migration - are
listed in [docs/runbooks/upgrade.md](docs/runbooks/upgrade.md#releases-that-need-action). Read it
before upgrading across several versions.
