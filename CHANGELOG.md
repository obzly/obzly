# Changelog

Each release's notes are generated from its commit subjects (see "Commit messages and versioning"
in [CONTRIBUTING.md](CONTRIBUTING.md)) and published with the release on GitHub Releases, together
with its image, `ghcr.io/obzly/obzly:<version>` for `linux/amd64` and `linux/arm64`.

Releases that need action from operators - a new permission, a setting, a one-way migration - are
listed in [docs/runbooks/upgrade.md](docs/runbooks/upgrade.md#releases-that-need-action). Read it
before upgrading across several versions.
